# Agent Tycoon — Gaia Nexus Games (Game 1 of 10)

Build Gaia Nexus from one laptop into an AI empire. Tap the Core to earn Data, hire AI agents who earn automatically, buy upgrades, and prestige with Nexus Reset for permanent bonuses. Progress saves locally; agents keep earning while you're away (up to 8 hours).

Play: https://josel120.github.io/gaia-agent-tycoon/
All games: https://josel120.github.io/gaia-nexus-games/
Part of [Gaia Nexus](https://www.gaia-nexus.com/).
